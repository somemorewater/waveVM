What this build does

Working now

  • Desktop shell and navigation
  • Host, memory, and storage diagnostics
  • QEMU and qemu-img discovery
  • Verified Linux KVM accessibility check
  • Atomic, versioned local configuration

Not in this build

  • Creating or editing VM definitions
  • Virtual disks and ISO selection
  • Starting QEMU or connecting over QMP
  • Graphical guest console
  • Networking and image downloads
